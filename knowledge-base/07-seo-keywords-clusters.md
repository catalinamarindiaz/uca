# 07 — SEO: Clusters de Keywords

> Mapa inicial de intención. Validar volúmenes con Search Console + Keyword Planner (pendientes). Prioridad = intención de conversión × competencia estimada.

## Cluster 1 — Crédito entre particulares ⭐ (núcleo diferenciador)
**Intención**: alta conversión · **Competencia**: media-baja
- crédito automotriz entre particulares
- crédito para comprar auto a un particular
- cómo financiar un auto de marketplace / yapo
- comprar auto usado a particular con financiamiento
- crédito para comprar auto entre particulares Chile
- transferencia segura de auto usado con crédito

**Contenido**: guía pilar "Cómo comprar un auto a un particular de forma segura y financiado" + artículos satélite (marketplace, validación del vendedor, transferencia).

## Cluster 2 — Sin acreditar ingresos ⭐
**Intención**: alta · **Competencia**: baja
- crédito automotriz sin acreditar ingresos
- crédito auto para independientes
- crédito auto sin liquidaciones de sueldo
- financiamiento auto trabajador independiente

**Contenido**: landing del producto **Instantáneo** + guía para independientes/app-drivers.

## Cluster 3 — FAQ / soporte (cola larga, alta intención)
**Intención**: clientes + investigadores · **Competencia**: baja
- prepago crédito automotriz / prepago parcial
- alzamiento de prenda registro civil auto
- certificado de deuda crédito automotriz
- cómo pagar cuotas atrasadas crédito auto
- problema con PAC crédito automotriz

**Contenido**: centro de ayuda indexable (cada FAQ = página).

## Cluster 4 — Guías de modelos usados + financiamiento
**Intención**: media (investigación de compra) · **Competencia**: media
- (modelo) usado precio Chile + financiamiento (ej. Hyundai Tucson, Suzuki, Tesla)
- qué auto usado es más económico en combustible
- modelos más vendidos / populares Chile
- cuánto vale un (marca/modelo) en Chile

**Contenido**: ya existe tracción en el blog; escalar con plantilla "modelo usado: precio por año + cómo financiarlo con UNIDAD".

## Cluster 5 — Actualidad / tráfico amplio (awareness)
**Intención**: informacional · **Competencia**: alta · **Conversión**: baja
- precio bencina hoy Chile
- valor UTM este mes
- restricción vehicular hoy
- permiso de circulación / ley silla

**Contenido**: actualizar periódicamente; usar para enlazado interno hacia clusters 1–4.

## Cluster 6 — Marca y confianza (defensa)
**Intención**: navegacional/confianza
- unidad créditos opiniones
- unidad crédito automotriz es confiable
- (defensa de marca vs `creditosunidad.com` / alerta CMF)

**Contenido**: página de opiniones + artículo "cómo reconocer un crédito confiable" (ya existe) + reforzar verificación CMF.

## Priorización sugerida (primeras 6 semanas)
1. Cluster 1 (entre particulares) — pilar + 3 satélites.
2. Cluster 2 (sin acreditar ingresos) — landing producto Instantáneo.
3. Cluster 3 (FAQ prepago/prenda) — 5–8 páginas de ayuda.
4. Cluster 4 — 2 guías de modelos con mejor búsqueda.

> El agente de SEO/Contenidos (`agents/02-seo-contenidos.md`) toma estos clusters como backlog.
